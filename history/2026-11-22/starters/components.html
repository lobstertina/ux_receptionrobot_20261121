元件與互動

每一項都可以點來試；展開「怎麼叫用」可複製到線框頁。App 頁另載 proto-keyboard.js 才有模擬鍵盤。

1　底部面板

所在頁的延伸層：點遮罩、按 ESC、按 × 都會關，關了回到原頁。選項列高度與主按鈕一致（52）。面板裡有輸入框時，鍵盤升起只推面板，背後頁面不動。

怎麼叫用
<!-- 觸發鈕：data-wf-open-sheet＝打開底部面板 -->
<button type="button" class="btn btn--secondary" data-wf-open-sheet="sheet-sort">排序方式</button>

<!-- 面板本體：放在 .scr 最後面，預設 hidden -->
<div class="sheet-layer" id="sheet-sort" hidden>
  <div class="sheet" role="dialog" aria-modal="true" aria-labelledby="sheet-sort-title">
    <div class="sheet__grab" aria-hidden="true"></div>
    <div class="sheet__head">
      <p class="sheet__title" id="sheet-sort-title">排序方式</p>
      <button type="button" class="icon-btn sheet__close" aria-label="關閉" data-wf-close>×</button>
    </div>
    <div class="sheet__body">
      <!-- data-wf-select="single"＝單選；選了就關閉並提示 -->
      <div class="sheet__options" data-wf-select="single">
        <button type="button" class="sheet__option" aria-checked="true" data-wf-close>最新優先</button>
        <button type="button" class="sheet__option" aria-checked="false" data-wf-close data-wf-toast="已改為最舊優先">最舊優先</button>

2　返回／關閉去向與換頁轉場

同層推進＝由右推入、左上返回；獨立任務＝由下覆蓋、右上 ×。退場反向。返回走「上一動」，關閉退到進入任務之前，都不寫死頁碼。返回時底下那頁的捲動位置與已填內容都還在。

怎麼叫用
<!-- 同層推進（預設 push：由右推入）。data-wf-params＝帶給下一頁的參數 -->
<button type="button" data-wf-go="b1-detail.html" data-wf-params="id=3">查看明細</button>
<button type="button" data-wf-code="B1.2">下一步</button>

<!-- 獨立任務（cover：由下覆蓋），該頁導覽列只放右上 × -->
<button type="button" data-wf-code="C1.1" data-wf-transition="cover">開始新任務</button>

<!-- 左上返回＝回上一動；右上 ×＝關掉整串任務，回到進入前那頁 -->
<button type="button" class="icon-btn" aria-label="返回" data-wf-back>←</button>
<button type="button" class="icon-btn" aria-label="關閉" data-wf-close-page>×</button>

<script>
  WfProto.goCode("B1.2", {}, { transition: "push" });   // 推入
  WfProto.goCode("C1.1", {}, { transition: "cover" });  // 覆蓋
  WfProto.goBack();   // 返回上一動
  WfProto.close();    // 關閉獨立任務
</script>

4　對話框

只有單按鈕、左右雙按鈕兩種。要使用者做決定的對話框點遮罩不會關；ESC＝按取消。輸入型只給短輸入（單一欄位，例：重新命名）：開啟時預帶原值並全選、不顯示錯誤；「儲存」一律可按，清空後按下才在輸入框下方顯示「請輸入 1～20 個字的名稱」，改對後錯誤消失。多欄位或長內容改用底部面板或獨立頁。

目前名稱：十月的紀錄

怎麼叫用
<!-- 寫好在頁面裡的對話框：data-wf-open-alert＝打開；data-wf-close＝關閉；data-wf-toast＝關閉後提示 -->
<button type="button" data-wf-open-alert="dlg-logout">登出</button>
<div class="alert-layer" id="dlg-logout" hidden>
  <div class="alert" role="alertdialog" aria-modal="true">
    <p class="alert__title">要登出嗎？</p>
    <div class="alert__acts">
      <button type="button" class="alert__btn" data-wf-close data-wf-esc>取消</button>
      <button type="button" class="alert__btn alert__btn--danger" data-wf-close data-wf-toast="已登出">登出</button>
    </div>
  </div>
</div>

<script>
  // 臨時產生（單按鈕：失敗類只留標題）
  WfProto.alert({ title: "儲存失敗" });
  // 輸入型（短輸入）：預帶原值；儲存一律可按，空白時按下才顯示錯誤
  WfProto.alert({
    title: "重新命名",
    input: { value: "十月的紀錄", maxLength: 20, emptyMessage: "請輸入 1～20 個字的名稱" },
    actions: [
      { label: "取消", role: "cancel" },
      { label: "儲存", role: "primary", onClick: function (value) { WfProto.toast("已重新命名"); } }
    ]
  });
</script>

5　輕提示

只說「已經發生」的結果；統一停留 3 秒；出現在置底區上方 12px，不壓住輸入框與按鈕；同時只有一個。可復原的操作附「復原」文字鈕，停留 5 秒。

怎麼叫用
<button type="button" data-wf-toast="已複製連結">複製連結</button>
<script>
  WfProto.toast("已儲存");   // 3 秒後自動消失
  // 可復原的操作：附「復原」文字鈕，停留 5 秒
  WfProto.toast("已封存", { action: { label: "復原", onClick: function () { WfProto.toast("已復原"); } } });
</script>

6　浮動更多選單＋刪除流程＋兩段確認

更多選單只靠陰影浮起、不壓遮罩，點外面或 ESC 收起。刪除：更多 → 刪除 → 確認對話框（紅字）→ 對話框立刻關 → 輕提示「刪除中」→「已刪除」；失敗才再跳對話框。嚴重後果（刪除帳號）用兩段確認。

怎麼叫用
<!-- 列右側的更多鈕：data-wf-popmenu＝打開浮動選單 -->
<button type="button" class="icon-btn" aria-label="更多" data-wf-popmenu="row-menu">⋯</button>

<!-- 每一列共用同一份選單：打開時記住是哪一列（最近的 data-wf-row、tr 或 li），選單動作自動作用在那一列 -->
<div class="popmenu" id="row-menu" role="menu" hidden>
  <button type="button" class="popmenu__item" role="menuitem" data-wf-open-edit="edit-row">編輯</button>   <!-- 帶入該列 data-wf-cell 的值 -->
  <button type="button" class="popmenu__item" role="menuitem" data-wf-row-copy>建立副本</button>
  <!-- data-wf-delete 不填值＝刪除成功後移除觸發的那一列；填值＝移除指定元素 -->
  <button type="button" class="popmenu__item popmenu__item--danger" role="menuitem"
          data-wf-delete data-wf-delete-title="要刪除這筆紀錄嗎？">刪除</button>
</div>
<!-- 列上：data-wf-cell＝要帶進抽屜哪個欄位 id；data-wf-row-title＝建立副本時加「（副本）」的文字 -->
<li class="list-row"><span class="list-row__title" data-wf-cell="row-name" data-wf-row-title>週末採買清單</span> …</li>

<!-- 兩段確認：再加 data-wf-delete-second（第二次確認的標題） -->
<button type="button" class="btn btn--danger" data-wf-delete
        data-wf-delete-title="要刪除帳號嗎？" data-wf-delete-second="確定要永久刪除帳號？">刪除帳號</button>

<script>
  WfProto.deleteFlow({ target: "#rec-3", title: "要刪除這筆紀錄嗎？" });  // 程式寫法
  WfProto.popmenu.row("row-menu");   // 選單最近一次是從哪一列打開的（自訂動作用）
</script>

    多值與範圍篩選、統計數字卡連動

    一個條件可以選多個值：「狀態」下拉可複選（清單不關，選項前有勾選框）；「門市」的「北部門市」一個選項代表兩家門市。「金額」是數值區間（填最低、最高，只填一邊＝以上／以下；最低大於最高會擋下並說明），「下單日期」是日期區間。每個條件都變成可移除的標籤，同一組值只列一個名稱：選了「未結案」（三種狀態的群組）時，它包含的單項照樣打勾但不另列；「我的門市」與「台北大安店」是同一個值，標籤只顯示使用者實際點的那一個名稱。上方統計數字卡點了直接篩選表格（「未結案」＝待付款、待出貨、處理中三種），再點一次取消；用下拉改條件或移除標籤時，卡片選中態跟著同步。手機寬統計卡維持兩欄。這張表沒有批次動作，所以不顯示勾選欄；列右側「⋯」滑鼠滑過或鍵盤聚焦該列才出現（觸控裝置、手機寬一律顯示）；每一列共用同一份「⋯」選單，選單記住是哪一列打開的：「編輯」帶入該列的訂單編號與門市、儲存後寫回該列，「建立副本」在該列下方插入一份，「刪除」移除該列，都不用自寫程式。最左欄星號可收藏。
